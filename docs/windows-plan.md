# Windows 重实现计划

本页是待验证的设计路线，不是从 Fig 恢复的内部架构。

## 阶段一：行为规格

在 Mac 上完成一个补全流程，明确输入、输出、状态、按键、错误和性能观察。以 `specs/completion.md` 的可重复用例作为完成标准。

## 阶段二：最小 Windows 原型

根据真实需求选择一个 shell 和终端作为首个支持组合。若选择 PowerShell，可调查 PSReadLine 的扩展能力；若需要独立弹窗，再验证终端光标定位、焦点和键盘输入方案。技术选择须基于当时官方接口文档与实测，暂不锁定框架。

划分候选生成、排序/过滤、交互展示、文本插入与 shell 适配。先使用自行编写的最小候选数据，避免将第三方补全数据的许可假设为可用。

## 阶段三：兼容性验证

从已确认的用例扩展至路径空格、引号、中文、行中编辑、不同工作目录及目标 shell/terminal 版本。分别记录 Mac 观察和 Windows 实测。

## 阶段四：打包与维护

行为和权限范围验证后再处理安装、卸载、配置迁移、错误日志和发布。公开发布前明确本项目代码的许可证及第三方依赖许可。
